# Bugs & Suspicious Behavior Found During Refactoring

1. **[FIXED]** **Slow-motion `TimeScaleDriver.update` arguments were swapped** (`src/game/game.ts`): `TimeScaleDriver.update` expects `(realDt, planarSpeed, maxSpeed, ...)`, but `WALK_SPEED` was passed before `this.player.planarSpeed`, keeping time at full speed when idle. Fixed by passing `this.player.planarSpeed` first and `WALK_SPEED` second.
2. **[FIXED]** **Debug time-scale toggles (F2/F3) were active in normal gameplay and persisted across level starts** (`src/game/game.ts`): F2/F3 are now gated behind `import.meta.env.DEV`, and `resetWorld()` resets `this.loop.time.lock = "none"`.
3. **[FIXED]** **Results "Accuracy" measured `min(kills, shots) / shots`** (`src/game/world.ts`, `src/game/game.ts`, `src/ui/ui.ts`): `World` now tracks actual player projectile hits on enemies (by unique `shotId`) in `stats.hits`, and `Ui.showResults` computes accuracy from `hits / shots`.
4. **[FIXED]** **Exit trigger ignored vertical position (Y) and grounding** (`src/game/world.ts`): `World.checkWin` now requires `this.player.grounded` and `Math.abs(this.player.pos[1]) < 1.5` in addition to the horizontal exit rectangle.
5. **[FIXED]** **Fixed-timestep accumulator dropped simulation time on slow frames** (`src/engine/time.ts`): Increased `MAX_STEPS_PER_FRAME` to `16` (covering a full `MAX_REAL_DT = 0.1s` frame at 120 Hz) and stopped zeroing `this.accumulator` when the step cap is hit.
6. **[FIXED]** **Replay viewmodel bobbing used distance from world origin instead of accumulated stride** (`src/game/replay.ts`, `src/game/game.ts`): `ReplayPlayer` now accumulates horizontal `stride` across replay frames and `Game.render` uses `this.replay.stride`.
7. **[FIXED]** **Screen flash still played when `reduceMotion` was enabled** (`src/game/game.ts`): `Game.updatePost` now zeroes `p.flash` when `reduceMotion` is enabled.
8. **[FIXED]** **Clicking PLAY / Level 1-1 did nothing because level 0 was treated as locked** (`src/ui/ui.ts`): `Ui.isUnlocked(index)` checked `if (index < 0) return true;` instead of `if (index <= 0) return true;`, causing `levels[-1]` to be `undefined` and `startLevel(0, true)` to return early.
9. **[FIXED]** **Horizontal mouse look was inverted** (`src/game/player.ts`): `PlayerController.look` added `input.mouseDx * s.sensitivity` to `this.yaw`, but `forward` uses `(-sin(yaw), 0, -cos(yaw))`, so positive `yaw` turns left. Changed to `this.yaw -= input.mouseDx * s.sensitivity;`.
